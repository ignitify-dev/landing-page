Integrations/Catalog/stream

stream

Serve a live audio or video stream that viewers open in a browser.

MediaSettings + code, runs ffmpegPro plan or higher

What you no longer build

  • The HTTPS server and the player page that viewers open in a browser.
  • The viewer link and the progress that the caller gets while the stream runs.
  • The ffmpeg process, and a clean stop when the run is cancelled.

Add it to a task

Read the plan first. --dry-run shows every setting and changes nothing. Then run it again and answer y.

What it writes into task.yaml

  • execution.network: bidirectional, inbound_port 8080, route /live/, inbound_max_concurrent 16
  • execution: duration long, interaction continuous
  • build.system_packages: ffmpeg
  • run.preset: at least std.medium

What you add yourself

  • For an https:// source, its host in execution.network.egress_allow. A file on the VM needs no host.

Use it in your code

Limits

  • HLS over HTTPS only, with a few seconds of delay.
  • No ingest: you cannot send a stream into the task.
  • One stream per task, for a small audience.

All options are in the README. To check, upgrade or remove an integration, see the Integrations guide.
