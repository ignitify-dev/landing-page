Integrations

An integration gives a task what it needs for one service. One command writes the settings into your task.yaml: secret names, network, system packages and the smallest preset. Some integrations also give you code to import, for example to upload a file or serve a live stream.

You write only the task code. You do not write the settings and the plumbing that every task of that type repeats. You see every change before it is written, and you can always write the same settings by hand.
