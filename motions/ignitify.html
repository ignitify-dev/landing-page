03 · How it works

One run, from source code to result.

01

Deploy

The CLI uploads the task source. Node, Python, Go or Rust.

02

Build

A build VM makes one code image that cannot change.

03

Admit

Quota and plan limits are checked under a lock.

04

Boot

The platform picks a host, reserves space and boots a jailed MicroVM.

05

Run

The code runs. The result returns. The VM is reused or torn down.

The tenant sends code and a payload. The platform does all the other steps.

06 · Run it as a platform

Safe, and also practical.

Warm reuse

A VM with the same shape serves the next run of the same deployment. No new boot.

Bounded capacity

Each VM is reserved in a ledger before it boots. A host is never over-booked.

Nothing leaks

Reapers take back stuck runs, idle VMs and images of deleted deployments. Each store they own has a limit.
