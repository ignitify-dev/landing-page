05  The walls

Own VM. Own kernel.A jail. No privileges.

Each workload runs in its own small VM, with its own kernel.
A jail surrounds it. Your code has no privileges.
Two live VMs never share a user id.
06  The network

No network,unless you list the hosts.

your task
host rules
api.example.com✓ on your list
another VM✗ blocked
By default, a task has no network.
If it needs one, it reaches only the hosts you list.
A VM cannot reach another VM. Host rules decide, not the guest.
