Your first real task

Take the hello task from the Quickstart. Change its code, send it input, read the result, and see an unchanged deploy reused.

1 · Edit run()

Open tasks/hello/index.ts. run(payload, ctx) gets the JSON you pass with --payload. Whatever it returns is the result.

2 · Deploy the change

New code means a new build, so reused is false.

3 · Run it with a payload

The payload is JSON. It applies to this run only; task.yaml is never changed.

Note

Bad JSON is refused before anything is sent: Error: --payload is not valid JSON: …

4 · Read the logs

Logs hold what the task printed. The result holds what it returned.

5 · Deploy again, unchanged

The same code gives the same deployment. Nothing is built, and the line says so.

Tip

A run uses the latest deploy. To run an older one, pass --deployment <id>.

Size limits

A payload is at most 10 KiB and a result at most 10 KiB. For more data, write it to your own store from inside the task and return a link. See Presets and limits.
