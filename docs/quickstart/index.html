Quickstart (5 min)

Four commands take you from an empty folder to a finished run. You need the ignitify CLI and an API key (a page on install steps is coming soon).

1 · Create the task

This reserves the name hello and writes the starter files to ./tasks/hello.

Note

The starter is Node. Add --lang python, --lang go or --lang rust for another language.

Note

A registered name stays yours, so check the spelling first.

2 · Deploy it

The CLI uploads the folder and waits until the platform has built it. Deploy the same code again and the build is reused.

Tip

Ctrl+C stops the wait, not the build.

3 · Run it and wait

The run boots its own MicroVM. --wait follows it to the end and prints the result. The exit code is 0 only when the run is COMPLETED.

Note

With no --deployment, a run uses the latest deploy of the task. If that deploy is still building or failed, the command stops and says so.

4 · Read the logs

Use the resource_id from the run, or its id. Both work.

That is the whole loop. Next, change the code and pass input to the task.
