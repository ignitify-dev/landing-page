What is Ignitify

Ignitify runs your code in a Firecracker MicroVM. Your code gets its own VM, with its own kernel. A warm VM can serve your next run.

  • You write a task: a folder with your code and a task.yaml.
  • You deploy it. The platform builds it once.
  • You run it. A run boots a MicroVM, or takes a warm one.
  • You say what the task needs. The platform picks how to run it.
  • A VM is torn down after its run, unless you ask to keep it warm.

Three terms

Term
Id
What it is
task
tsk_…
A name you keep. task:create reserves it.
deployment
dep_…
One built version of the task. Same code, same deployment.
run
run_…
One job in one MicroVM, started from a deployment.

Every id also has a long UUID. Either one works in a command.
