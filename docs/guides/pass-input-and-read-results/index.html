Pass input and read results

Send JSON to a run with --payload. Read what the task returns with run:get.

1 · Read the payload in your task

The first argument of run is the payload, and what you return is the result.

2 · Set a default payload

run.payload in task.yaml is the input when you pass none.

3 · Pass a payload for one run

--payload replaces the default for this run only. It must be valid JSON.

Tip

Add --wait to follow the run and print its result in one command.

4 · Read the result

run:get prints the run and its Result. A failed run shows the error there.

5 · Read the logs

run:logs prints the console output of the run. Your own console.log lines start with [task].

6 · Stay inside the size limits

A payload is at most 10 KiB and a result at most 10 KiB. The CLI refuses a payload that is too big before it sends it.

Note

A result over the limit fails the run. Send big data to your own store from inside the task and return a link. See Presets and limits.
