Stop and clean up

Stop a live run with run:cancel. Remove runs, deployments and tasks with the :delete commands.

1 · Cancel a run gracefully

The run is asked to stop, and it is killed if it does not finish in time. Add --grace <ms> to ask for a longer wind-down.

Note

Every command that deletes or cancels asks first. -y (or --yes) skips the question, and without a terminal the CLI refuses unless you pass it.

2 · Cancel a run now

--force kills the run at once, even on a pinned VM. It cannot be combined with --grace.

3 · Delete a run

run:delete removes the run record. A live run is marked CANCELLED, but its VM is not stopped, so use run:cancel first.

4 · Delete a deployment and its runs

deployment:delete also deletes every run of that deployment, and the last line counts them.

5 · Delete a task and everything under it

task:delete lists what will go first, then deletes the task, its deployments and its runs. Your files stay; only the local .ignitify/ link is removed.

Warning

Deleting a task cancels its live runs and destroys their VMs. The list names them first, even with -y.
