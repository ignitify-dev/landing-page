Guides

Use secrets

Store a value once with secret:set. A task reads it by name, so it is never in your code or on the command line.

1 · Name the secret in task.yaml

Use capital letters, digits and underscores, starting with a letter.

2 · Store the value from stdin

--stdin reads the value from a file or a pipe, so it stays out of your shell history.

Warning

A value on the command line is refused, and so is --value. Rotate any secret you typed there.

3 · Read it in your task

The run gets the secrets you named in ctx.secrets, keyed by name.

Note

In Python use ctx.secrets["DB_PASSWORD"]. Go has ctx.Secrets and Rust has ctx.secrets. A run fails if a name you declared has no value yet.

4 · List the names

secret:list shows names and update times. A value can never be read back.

5 · Delete one

secret:delete asks first; -y skips the question.
