Run later

Start a run at a set time with --at. List the pending runs and cancel one with schedule:list and schedule:cancel.

1 · Schedule the run

Give --at a future time in ISO-8601, in UTC when it ends with Z.

Note

A time in the past is refused with at must be in the future.

2 · List the pending runs

schedule:list shows each pending schedule, soonest first.

3 · Cancel one

schedule:cancel asks first; -y skips the question, and a script needs it.

4 · Do not combine it with --wait

A scheduled run has no run id until it fires, so the CLI refuses --at with --wait.

5 · Find the run after it fires

When the time comes, the schedule leaves the list and the run shows up in run:list.

Note

Cancelling a schedule that has fired, or is firing now, fails with exit code 1. Then look for the run instead.
