Tier schema

A tier is 43 entitlement columns, plus 5 identity columns and 4 derived ones. Every column has a live gate — a column with no enforcement is a build failure, not a TODO.

Null is deliberately asymmetric

A null count, rate or network ceiling means unlimited. A null size or time limit means the host default, not unlimited — an unbounded per-request payload is a denial-of-service surface, not a generous plan. A capability defaults to deny.

All or nothing

Publishing a tier requires every column. Dropping one is a compile error, not a silent default — that is what stops a new column from quietly meaning “unlimited” for every existing tier.

One deliberate exception: retry is allowed by default. It is a reliability default rather than a capability, and it can never promote a security-terminal failure.
