CLI reference

Deployments

See and delete the builds of your tasks.

deployment:list

List your live deployments with the size of each image.

  • needs API key
  • --json: full
FlagValueDefaultDescription
--limitN—Rows on the page. The server sets the default and the largest value.
--after<iso>—Only rows after this ISO 8601 time.
--after-id<id>—Page cursor. Pass the id of the last row of the page before.

Note

The last line shows the total size of all your images against your plan's image limit.
Related
  • deployment:get
  • deployment:delete
  • task:deploy

deployment:get

Show one deployment: status, size, integrity and build details.

  • needs API key
  • --json: full
FlagValueDefaultDescription
<deployment-id>required——The deployment id, from task:deploy or deployment:list.

Note

Integrity shows ok or missing, and a failed build also shows its reason and log.
Related
  • deployment:list
  • task:run
  • hook:create

deployment:delete

Delete a deployment together with its runs.

  • needs API key
  • asks to confirm
  • deletes data
  • --json: full
FlagValueDefaultDescription
<deployment-id>required——The deployment id.
--yes, -y——Skip the question.

What happens

  1. Prints what it will delete.
  2. Asks you to confirm, unless you pass --yes.
  3. Soft-deletes the deployment and all its runs.
  4. Prints how many runs, VMs and pins went with it.

Note

The delete cascades: every run of the deployment goes with it.
