CLI reference

VMs

See the VMs that run your tasks, and delete them.

vm:list

List your live VMs with their state, age and idle time.

  • needs API key
  • --json: full
More examples (1)
FlagValueDefaultDescription
--deployment-idD—Only VMs of this deployment.
--task-nameN—Only VMs of this task.
--presetP—Only VMs of this instance class.
--older-than24h—Only VMs older than this age, for example 24h.
--limitN—Rows on the page. The server sets the default and the largest value.
--after<booted_at>—Boot time of the last row of the page before (ISO 8601). Use with --after-vm-id.
--after-vm-id<vm-id>—VM id of the last row of the page before. Use with --after.
--pinned——Only pinned VMs, the ones that stay up until you delete them.

Note

A pinned VM that has been idle for a long time shows a warning mark in the idle column.

Note

For the next page, take booted_at and vm_id of the last row from the --json output.

vm:delete

Tear down a VM by hand.

  • needs API key
  • asks to confirm
  • deletes data
  • --json: full
More examples (1)
FlagValueDefaultDescription
<vm-id>required——The VM id.
--yes, -y——Skip the question.
--force——Allow the delete of a pinned VM. It does not skip the question.

What happens

  1. Reads the VM, and refuses a pinned VM unless you pass --force.
  2. Prints what it will tear down.
  3. Asks you to confirm, unless you pass --yes.
  4. Deletes the VM, which fails a run that is busy on it.

Note

A pinned VM is a permanent standby, so a delete needs --force, idle or busy.

Note

A busy VM fails its in-flight run when it is deleted.
