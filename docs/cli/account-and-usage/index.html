Account and usage

Sign in and out, see your identity, limits and usage, the version and help.

login

Sign this machine in and save its API key.

  • offline
  • --json: none
FlagValueDefaultDescription
--no-browser——Print the sign-in page, but do not open it.
--name<label>—A label for this machine's key. The default is the hostname.

What happens

  1. Asks the platform for a sign-in code and prints it.
  2. Waits while the code is approved.
  3. Saves the new key in a file that only you can read.
  4. Prints the account it signed in to.

Note

A second login on the same machine replaces its key, so use --name to keep two machines with one hostname apart.

Note

The key dies after a long time without use, and each use renews it.

logout

Revoke this machine's key and delete the saved file.

  • offline
  • deletes data
  • --json: none
More examples (1)

What happens

  1. Asks the platform to revoke the saved key.
  2. Deletes the saved file.
  3. Prints the result.

Note

When the platform cannot be reached, the file is still deleted and a warning says the key may still work.

usage

Show what you used in one month, by axis.

  • needs API key
  • --json: full
FlagValueDefaultDescription
--periodYYYY-MM—The month to show, as YYYY-MM.
--axiscompute|network|network_in|disk|scratch|runs|pin|build—Show one axis only, for example compute.
--vm<vm-id>—Only the usage of this VM.
--run<run-id>—Only the usage of this run.
--runs——Add the lines behind the totals, one per run.
--vms——Add the lines behind the totals, one per VM.
--json——Print the report as JSON.

Note

The report shows quantities only, with no price.

Note

A --vm or --run filter narrows the lines, but the counters at the bottom stay for the whole month.

usage:export

Export the usage lines of a month as JSON or CSV.

  • needs API key
  • --json: full
FlagValueDefaultDescription
--periodYYYY-MM—The month to export, as YYYY-MM.
--axiscompute|network|network_in|disk|scratch|runs|pin|build—Export one axis only, for example compute.
--vm<vm-id>—Only the lines of this VM.
--run<run-id>—Only the lines of this run.
--csv——Print the lines as CSV.
--json——Print the lines as a JSON array.

Note

Name exactly one format, --json or --csv, so the shape never depends on a forgotten flag.

Note

It prints the ledger lines and nothing else: no totals, no header text, no colour.

help

Print the usage of every command, or of one command.

  • offline
  • --json: none
FlagValueDefaultDescription
<command>——A command name. Leave it out to print every command.

Note

ignitify <command> --help and ignitify <command> -h print the same lines.

Note

A word that is not a command prints Error: unknown command: <word> and exits 1.
