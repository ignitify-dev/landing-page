Schedules

See and cancel runs that wait for a time.

schedule:list

List runs that wait for a time, soonest first.

  • needs API key
  • --json: full
More examples (1)

Note

A schedule is not a run, and no run exists until it fires.
Related
  • schedule:cancel
  • task:run
  • run:list

schedule:cancel

Cancel one scheduled run so that it never fires.

  • needs API key
  • asks to confirm
  • deletes data
  • --json: full
FlagValueDefaultDescription
<sch-id>required——The schedule id, from task:run --at or schedule:list.
--yes, -y——Skip the question.

What happens

  1. Prints which schedule it will cancel.
  2. Asks you to confirm, unless you pass --yes.
  3. Cancels the schedule.
  4. Prints the schedule id.

Note

If the schedule is missing, already fired or firing now, the command says so and exits 1.
