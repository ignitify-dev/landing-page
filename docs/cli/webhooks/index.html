Webhooks and notify

Create webhooks that start runs, and set a callback URL for a deployment.

hook:create

Create a webhook that starts a run of one task.

  • needs API key
  • --json: full
More examples (1)
FlagValueDefaultDescription
<deployment-id>required——The deployment the webhook belongs to.
--task-namerequired<name>—The task that each run starts. Required.

Note

The signing secret in the reply is shown once, and hook:list never returns it.

Note

A webhook body over 10 KiB is refused before the signature is checked.
Related
  • hook:list
  • hook:delete
  • notify:set

hook:list

List the webhooks of a deployment, oldest first.

  • needs API key
  • --json: full
FlagValueDefaultDescription
<deployment-id>required——The deployment id.
--limitN—Rows on the page. The server sets the default and the largest value.
--after<iso>—Only rows after this ISO 8601 time.
--after-id<id>—Page cursor. Pass the id of the last row of the page before.

Note

The signing secret is never listed, so a lost secret needs a new hook.
Related
  • hook:create
  • hook:delete

hook:delete

Delete a webhook.

  • needs API key
  • asks to confirm
  • deletes data
  • --json: full
FlagValueDefaultDescription
<hook-resource-id>required——The id of the hook (hok_…), not the id of the deployment.
--yes, -y——Skip the question.

What happens

  1. Prints which webhook it will delete.
  2. Asks you to confirm, unless you pass --yes.
  3. Deletes the webhook.
  4. Prints the hook id.

Note

A sender that posts to the webhook is refused from then on.
Related
  • hook:list
  • hook:create

notify:set

Set or clear the callback URL of a deployment.

  • needs API key
  • --json: full
More examples (1)
FlagValueDefaultDescription
<deployment-id>required——The deployment id.
--url<https://…>—The HTTPS address to call. Needs --secret-stdin.
--clear——Remove the callback URL. Cannot be used with --url.
--secret-stdin——Read the signing secret from stdin. Needed with --url.

Note

The secret has a minimum length (the usage text names it), and a --secret flag is refused.

Note

Nothing is sent if a flag is refused, and stdin is not read.
