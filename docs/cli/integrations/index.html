Integrations

Add an integration package to a Node task and write its settings into task.yaml.

integration:add

Add an integration package to a Node task and write its settings.

  • no API key
  • asks to confirm
  • --json: full
More examples (1)
More examples (2)
FlagValueDefaultDescription
<name>required——The integration name. The npm package is @ignitify-integrations/<name>.
--dir<base-dir>$IGNITIFY_TASKS_DIR, else tasksFolder that holds your task folders.
--yes, -y——Apply the plan without the question. Use it when no terminal is attached.
--taskrequired<slug>—The task folder name to add the integration to.
--dry-run——Show the plan, then stop. Nothing in the task changes.

What happens

  1. Downloads the latest version of the package into a temporary folder, not into the task.
  2. Shows the plan, which is every change to task.yaml and what you must add yourself.
  3. Asks you to confirm, unless you pass --yes or --dry-run.
  4. Installs that version with npm in the task folder, then writes task.yaml.

Note

Nothing in the task changes before you answer y.

Note

An N, --dry-run or a refused plan changes nothing, so package.json, the lockfile, node_modules and task.yaml stay the same.
