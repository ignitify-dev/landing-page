Secrets

Store secret values by name, which can never be read back.

secret:set

Store a secret value under a name, read from stdin.

  • needs API key
  • --json: full
More examples (1)
FlagValueDefaultDescription
<NAME>required——The secret name. List it in secrets in task.yaml to use it.
--stdinrequired——Read the value from stdin. A value on the command line is refused.

Note

Secrets are write-only, and no command reads a value back.

Note

A value typed on the command line is in your shell history, so rotate it if that happens.

secret:list

List the names of your secrets and when each was updated.

  • needs API key
  • --json: full
More examples (1)

Note

It shows names only, because values can never be read back.
Related
  • secret:set

secret:delete

Delete a secret.

  • needs API key
  • asks to confirm
  • deletes data
  • --json: full
FlagValueDefaultDescription
<NAME>required——The secret name.
--yes, -y——Skip the question.

What happens

  1. Prints which secret it will delete.
  2. Asks you to confirm, unless you pass --yes.
  3. Deletes the secret.
  4. Prints the name.

Note

The value is write-only, so a deleted secret cannot be read back.
